# Personal IPTV Playlist

This extension downloads the latest public playlist generated by `iptv-org/iptv`, applies local filters, conservatively checks stream availability, and writes a standard M3U playlist for IPTV applications.

It does not modify the upstream `streams/` data or the existing playlist generation commands.

## Requirements

- Node.js 22
- Network access to `iptv-org.github.io`, the iptv-org API, and selected stream hosts

## Run locally

```powershell
npm ci
npm run personal:generate
```

The command creates:

- `dist/playlist.m3u`: the playlist to import or subscribe to
- `dist/report.json`: source, filter, deduplication, and availability statistics

Outputs are replaced only after a complete successful run. A download failure or an output below `safety.minimumOutputStreams` leaves the previous playlist unchanged.

## Configure

Edit `personal/config.json`.

The default source is the China playlist because it is small enough for a practical daily availability check:

```json
"sources": [
  "https://iptv-org.github.io/iptv/countries/cn.m3u"
]
```

Use `https://iptv-org.github.io/iptv/index.m3u` for all countries, but filter it before enabling availability checks at large scale. Multiple source URLs are merged before deduplication.

Filter arrays use OR within the same dimension and AND across dimensions. Empty arrays disable that dimension.

- `countries`: ISO 3166-1 alpha-2 codes such as `CN`, `HK`, `US`
- `languages`: ISO 639-3 codes such as `zho`, `eng`
- `categories`: category IDs or names such as `news`, `sports`
- `includeNames`: case-insensitive required channel-name fragments
- `excludeNames`: case-insensitive blocked channel-name fragments
- `excludeLabels`: labels such as `Geo-blocked` or `Not 24/7`
- `minimumVerticalResolution`: `720` keeps 720p and above when quality metadata exists

Availability checks reject only status codes listed in `availability.rejectStatusCodes`. Timeouts, unsupported formats, and other uncertain results remain in the playlist and are counted under `retainedWithWarning` to avoid deleting temporarily unavailable or region-limited streams.

## Run every day at 02:00

For Windows, open PowerShell in the repository and run:

```powershell
.\personal\install-windows-task.ps1
```

The installer registers a daily task for 02:00 local time. It does not replace an existing task with the same name.

The included `.github/workflows/personal-playlist.yml` runs at `18:00 UTC`, which is `02:00` the next day in `Asia/Shanghai`, and deploys `dist/` to GitHub Pages. In the fork repository settings, set Pages source to **GitHub Actions**. The subscription URL is then:

```text
https://<account>.github.io/<repository>/playlist.m3u
```

The upstream update workflow starts around 08:00 Asia/Shanghai, so a 02:00 run consumes the latest version available at that time, normally the previous upstream batch.

Run availability checks from the same network as the IPTV player when geographic or ISP restrictions matter. GitHub-hosted runners test from a data-center network and can produce different results.
